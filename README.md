# gp-forge

高斯过程回归（Gaussian Process Regression）实验室 —— **零依赖、零构建的单文件 HTML**，在浏览器里跑完整的核矩阵构造、Cholesky 推断、边际似然解析梯度与超参梯度上升，并自带 8 条可交叉验证的不变量自检。

打开 `index.html` 即可用，无需服务器、无需 npm install。

## 能看什么

- **后验回归**：画布上点击加点（Shift+点击删除最近点），实时画出后验均值 μ、95% 置信带 ±2σ，以及后验采样函数
- **超参调节**：长度尺度 ℓ / 信号幅度 σ<sub>f</sub> / 噪声 σ<sub>n</sub> 三个对数刻度滑动条，实时看置信带怎么变
- **多起点超参优化**：按边际似然 log p(y|X,θ) 做梯度上升，画出上升曲线；解释为什么单起点会掉进局部最优
- **核矩阵热图**：K + σ<sub>n</sub>²I 的可视化，附带 Cholesky 是否成功与 log|K|
- **不变量自检面板**：8 项硬断言，浏览器内实时计算，与无头 Node 断言跑的是同一份 engine 代码

## 算法

RBF 核 `k(x,z) = σ_f²·exp(−(x−z)² / 2ℓ²)`，观测模型 `y = f(x) + ε, ε~N(0,σ_n²)`。

| 步骤 | 公式 | 复杂度 |
|------|------|--------|
| 核矩阵 | Kᵢⱼ = k(xᵢ,xⱼ) | O(n²) |
| Cholesky | K_y = K + σ_n²I = LLᵀ | O(n³/3) |
| 后验均值 | μ\* = K\*ᵀ α，α = K_y⁻¹y | O(n²m) |
| 后验方差 | σ\*² = k\*\* − vᵀv，v = L⁻¹K\* | O(n²m) |
| 边际似然 | −½yᵀα − ½log\|K_y\| − n/2·log2π | O(n³) |
| 解析梯度 | ∂/∂θ = ½tr[(ααᵀ − K_y⁻¹)·∂K_y/∂θ] | O(n³) |

采样用 `x = μ + Lz`（后验协方差的 Cholesky × 标准正态）。

## 8 条不变量

| # | 不变量 | 验证套路 |
|---|--------|----------|
| 1 | 核矩阵对称 + 半正定（Cholesky 零 jitter 成功）+ RBF 平移不变 | 结构性质 + 等变性 |
| 2 | Cholesky 解 == 高斯消元解（部分选主元） | 参照实现 vs 主实现 |
| 3 | 无噪极限：后验均值在训练点 == y，方差 == 0 | 解析性质（插值） |
| 4 | 训练点后验方差 == σ_n²(1 − σ_n²·[(K+σ_n²I)⁻¹]ᵢᵢ) | 解析恒等式 |
| 5 | 信息单调性：观测增多，所有测试点后验方差不增 | 单调收敛定理 |
| 6 | 边际似然解析梯度 == 中心差分 | 梯度检验 |
| 7 | 多起点梯度上升：边际似然单调非减 + 长度尺度还原 | 精确还原真值 |
| 8 | 后验采样 20000 次：经验均值/标准差 == 解析 μ/σ | 蒙特卡洛交叉验证 |

## 一个真实的坑：边际似然曲面是多峰的

GP 的边际似然对超参**非凸**。经典陷阱：长度尺度 ℓ 初始化过大 → 模型平滑到无法解释数据起伏 → 只能把信号全解释成噪声 → σ_n 被推高，卡死在一个很差的局部最优（实测从 ℓ=3 单起点出发只到 −51.4，而真值是 −5.07）。

所以 `optimizeAuto` 用 3 个起点取最优，而不是从当前滑动条值单起点爬。每一轮内部用**回溯线搜索**保证边际似然严格不下降。

## 无头验证

```bash
node _smoke.js   # 1024/1024 PASS，写 _smoke.log
node _probe.js   # dump 内部状态到 _probe.txt，人眼复核
```

`_smoke.js` 用 `vm.runInContext` 从 `index.html` 抽出 `<script id="engine">` 在 Node 里跑，覆盖：

- 8 条内置不变量
- 120 组随机模型（n∈[1,12]）：核矩阵对称性、K+σ_n²I 严格正定、L·Lᵀ 复原、Cholesky==高斯消元、后验方差非负且 ≤ 先验 σ_f²、梯度检验
- 30 组信息单调性
- 边界条件：n=0（退化为先验）、n=1（解析解）、重复 x（奇异核走 jitter）、极端超参（ℓ=1e-3 / 1e3）
- 确定性：同 seed 数据与采样可复现
- 4 组多起点超参优化：logML 单调非减、优化后 ≥ 真值 logML、超参不跑飞

`_probe.js` 是探针：它用**独立的高斯消元求逆**重算一遍后验再与 Cholesky 路径对拍 —— 确认「全绿 ≠ 正确」。
